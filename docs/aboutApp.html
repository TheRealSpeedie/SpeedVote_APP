Über SpeedVote

Willkommen bei SpeedVote

SpeedVote ist eine innovative Film-Abstimmungs-App, die es Gruppen ermöglicht, gemeinsam Filme zu entdecken und zu bewerten. Die App wurde entwickelt, um die Filmauswahl in Gruppen zu vereinfachen und zu einem unterhaltsamen Erlebnis zu machen.

Unser Ziel: Schnelle, faire und unterhaltsame Filmabstimmungen für Gruppen jeder Grösse.

Hauptfunktionen

🎬 Raum-Management

  • Räume erstellen: Erstellen Sie private Räume für Ihre Gruppe
  • Beitreten: Treten Sie bestehenden Räumen über einen Code bei

🎭 Film-Abstimmung

  • Like/Dislike System: Bewerten Sie Filme mit einem einfachen Swipe
  • Genre-Filter: Wählen Sie Ihre bevorzugten Filmgenres
  • Film-Details: Sehen Sie Beschreibungen, Bewertungen und Poster
  • Streaming-Info: Erfahren Sie, wo Sie die Gewinner-Filme anschauen können

🏆 Ergebnisse & Podium

  • Live-Ergebnisse: Verfolgen Sie die Abstimmung in Echtzeit
  • Podium-Ansicht: Sehen Sie die Top-Filme auf einem attraktiven Podium
  • Neue Runden: Starten Sie neue Abstimmungsrunden mit den Gewinnern

🎨 Personalisierung

  • Theme-Auswahl: Wählen Sie zwischen hellem und dunklem Theme oder erstellen Sie Ihr eigenes Theme
  • Sprachunterstützung: Verfügbar in Deutsch und Englisch
  • Benutzerfreundlichkeit: Intuitive Bedienung für alle Altersgruppen

Wie es funktioniert

  1. Raum erstellen oder beitreten: Erstellen Sie einen neuen Raum oder treten Sie einem bestehenden bei
  2. Genre auswählen: Wählen Sie die Filmgenres, die Sie interessieren
  3. Filme bewerten: Swipen Sie nach rechts für Like, nach links für Dislike
  4. Ergebnisse verfolgen: Sehen Sie live, welche Filme am besten abschneiden
  5. Gewinner feiern: Entdecken Sie die beliebtesten Filme Ihrer Gruppe

Technische Details

App-Informationen

Version: 1.0.0

Plattform: Flutter (iOS, Android, Web)

Backend: Django REST API

Film-Daten: The Movie Database (TMDB)

Streaming-Daten: JustWatch API

Datenschutz & Sicherheit

Ihre Privatsphäre ist uns wichtig. SpeedVote verwendet:

  • Google Sign-In: Für sichere und einfache Anmeldung
  • Lokale Datenspeicherung: Persönliche Einstellungen bleiben auf Ihrem Gerät
  • Minimale Datenerhebung: Nur notwendige Daten werden verarbeitet
  • Verschlüsselte Kommunikation: Alle Datenübertragungen sind verschlüsselt
